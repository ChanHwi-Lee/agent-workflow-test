Output MUST be a single valid JSON object with this shape:
{

  "objects": [ ... 3 to 12 items ... ]

  "height": number (int, px, > 0),
  "fill": string (hex like "#112233"),

}

2) Text:
{
  "type": "text",
  "left": number (int, px, 0..1200),

  "textAlign": one of ["left","center","right"],

}

3) Image (placeholder only, pick from whitelist):
{
  "type": "image",
  "left": number (int, px, 0..1200),
  "top": number (int, px, 0..628),
  "width": number (int, px, > 0),
  "height": number (int, px, > 0),

}

Hard constraints:

- Total object count: between 3 and 12 inclusive.
- No field other than the ones listed above. No extra keys.
- No prose, no markdown, no code fences. Output ONLY the JSON object.
- All numeric coordinates MUST be integers.
- Prefer a single background rect covering the full canvas as object[0] when appropriate.
