# Agent Workflow Archive

이 디렉터리는 historical evidence 전용이다. 현재 구현 기준이나 다음 작업 지시로 직접 사용하지 않는다.

- `handoff/`: 과거 스레드/PR handoff, baseline evidence, cleanup 작업 기록.
- `historical-audits/`: 특정 시점의 capability 조사와 audit.

archive 문서 안의 경로, 파일명, 실행 명령은 작성 당시 기준일 수 있다. 현재 기준은 root의 `README.md`, AS-IS, roadmap, v6 SSOT를 따른다.
